# تطبيق القرآن الكريم - Quran App

## 📖 نظرة عامة
تطبيق Android متطور للقرآن الكريم يوفر تجربة قراءة وحفظ وتدبر شاملة مع ميزات حديثة ومبتكرة.

## ✨ الميزات الرئيسية

### المرحلة الأولى - الجوهر والوظائف المعقدة
- **إدارة البيانات المتقدمة**: قاعدة بيانات Room مع مزامنة Firebase
- **مزامنة الصوت والنص**: تقنية LRC للتظليل المتزامن
- **محرك البحث الذكي**: بحث متقدم مع FTS5 ودعم الذكاء الاصطناعي
- **نظام التحفيظ التفاعلي**: خوارزميات التكرار المتباعد
- **تقييم التلاوة بالـ AI**: تحليل الأداء وتصحيح الأخطاء

### المرحلة الثانية - الواجهات والتفاعل
- **واجهة Jetpack Compose**: تصميم حديث ومرن
- **عرض المصحف المتطور**: أنماط عرض متعددة مع تأثيرات بصرية
- **نظام الملاحظات الغني**: تنسيق متقدم مع التصنيف والمشاركة
- **التفسير التفاعلي**: مصادر متعددة مع الربط الموضوعي
- **التخصيص الشامل**: سمات وخطوط وإعدادات متقدمة

### المرحلة الثالثة - الهيكل والأساسيات
- **بنية Clean Architecture**: فصل الطبقات مع MVVM
- **نظام التنقل المتطور**: Bottom Navigation مع حالات متعددة
- **هوية بصرية متميزة**: تصميم روحاني مع رسوم متحركة

### المرحلة الرابعة - الميزات المتقدمة
- **المزامنة السحابية**: تزامن البيانات عبر الأجهزة
- **الميزات الاجتماعية**: إنجازات وتحديات جماعية
- **تحليلات الأداء**: مراقبة الاستخدام وتحسين التجربة

## 🛠️ التقنيات المستخدمة

### Core Technologies
- **Language**: Kotlin 100%
- **UI Framework**: Jetpack Compose
- **Architecture**: MVVM + Clean Architecture
- **Database**: Room + Firebase Firestore
- **Audio**: ExoPlayer
- **DI**: Hilt
- **Async**: Kotlin Coroutines + Flow

### Libraries & Dependencies
- **androidx.compose**: UI toolkit حديث
- **androidx.room**: قاعدة بيانات محلية
- **firebase**: خدمات سحابية
- **exoplayer**: تشغيل الصوتيات
- **hilt**: حقن التبعيات
- **navigation-compose**: تنقل الشاشات
- **datastore**: تخزين الإعدادات

## 📱 متطلبات النظام

- **Target SDK**: 34 (Android 14)
- **Compile SDK**: 34

## 🚀 التثبيت والإعداد

### 1. Clone المشروع
```bash
git clone https://github.com/username/quran-app.git
cd quran-app
```

### 2. إعداد Firebase
1. إنشاء مشروع Firebase جديد
2. إضافة ملف `google-services.json` إلى مجلد `app/`
3. تفعيل Authentication و Firestore

### 3. إعداد البيانات
```bash
# تحميل بيانات القرآن من المصادر الموثوقة
./scripts/download_quran_data.sh
```

### 4. Build المشروع
```bash
./gradlew build
```

